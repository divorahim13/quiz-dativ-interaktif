# Deutsch Lernen

Aplikasi belajar bahasa Jerman interaktif untuk latihan Dativ, review jawaban, dan flashcard Wortschatz per level.

## Fitur

- Quiz grammatik dengan skor dan review jawaban.
- Flashcard Wortschatz berdasarkan level A1 sampai B2.
- Tambah flashcard sendiri melalui template manual atau prompt AI.
- Penyimpanan flashcard custom di browser menggunakan localStorage.

## Menjalankan Project

```bash
npm install
npm run dev
```

Untuk build produksi:

```bash
npm run build
```
